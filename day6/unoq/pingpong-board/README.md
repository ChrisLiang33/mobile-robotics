# 🏓 Ping-Pong Board (UNO Q App Lab project)

Shows the Day 6 game live on the LED matrix: ball, paddle, and the current
streak as a bar along the bottom row. Subscribes to
`ME193/Rogers/ChrisLiang/live`, published 10×/s by `../../pingpong.py`.

Deploy with `../unoq.sh deploy` (USB) or `UNOQ_HOST=<ip> ../unoq.sh deploy`
(WiFi) — `unoq.sh` here defaults to this app.
